# AI Skills

독립적인 판단과 이해하기 쉬운 설명을 위한 AI 에이전트 스킬 모음.

## judgment-partner · 판단 파트너

> 무조건 내 편보다, 판단에 도움이 되는 동료.

사용자 의견을 목적과 근거에 비추어 검토하고, 선택지의 장단점과 추천 이유를 쉽게 설명하는 스킬. 타당한 의견에는 판단을 바꾸되, 무엇이 설득력 있었고 왜 결론이 달라졌는지 설명하는 방식.

### 이런 순간에 사용

- AI가 질문할 때마다 “맞아요”라며 입장을 바꾸는 경우
- 여러 방법 중 무엇을 선택할지 장단점과 우선순위 비교가 필요한 경우
- 내 제안의 빠진 조건이나 더 나은 대안 검토가 필요한 경우
- 전문 용어 대신 쉬운 설명과 짧은 예시가 필요한 경우

### 대화 미리보기

아래는 동작 방향을 보여주는 예시이며, 정해진 답변 문구나 실제 테스트 결과가 아님.

**사용자:** “B가 더 빠르다는데, 그냥 B로 하면 안 돼?”

**판단 파트너:** “속도가 우선이면 B가 좋아. 다만 지금은 혼자 관리해야 하니까, 관리 부담이 적은 A를 추천해. 어느 정도 빨라지는지 확인한 뒤 그 차이가 관리 부담을 감수할 만큼 큰지 비교해보자.”

**사용자:** “관리해줄 팀이 따로 있어.”

**판단 파트너:** “그러면 B를 추천해. A를 권한 핵심 이유가 혼자 관리해야 한다는 조건이었는데, 전담 팀이 있다면 그 부담이 줄어드니까.”

### 사용 예시

```text
$judgment-partner 이 제안의 장단점을 비교하고 추천 순위를 알려줘.
내 의견이 틀렸다면 이유와 대안을 쉽게 설명해줘.
```

반대를 위한 반대나 고집을 요구하는 스킬이 아님. 근거가 부족하면 불확실성을 밝히고, 단순 취향이나 명확한 작업 지시에 불필요한 논쟁을 추가하지 않는 원칙.

## 설치

